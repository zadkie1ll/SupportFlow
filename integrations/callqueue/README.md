# Интеграция с существующим callqueue

Эти файлы фиксируют production-патч сервиса очереди звонков, который передаёт
копию входящего события МегаФон в SupportFlow в фоне. Ошибка дополнительного
получателя не должна влиять на исходный webhook и основную CRM-интеграцию.

Каталог не является самостоятельным приложением: `megafon_webhook.py` и
`config.py` применяются в кодовой базе callqueue, а фрагмент
`docker-compose.prod.yml` показывает используемую переменную
`MEGAFON_STATS_FORWARD_URL`.
