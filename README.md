# SupportFlow

Сервис отдела сопровождения «Правбюро»: статистика звонков МегаФон ВАТС в
Telegram и безопасное временное замещение ответственных по сделкам в Bitrix24.

Актуальный production-код находится в [`call_stats_bot`](call_stats_bot). Он:

- принимает финальные события звонков МегаФон ВАТС;
- хранит статистику в SQLite и отправляет ежедневные отчёты в Telegram;
- обновляет имена выбранных сотрудников из API ВАТС;
- позволяет администраторам временно переводить активные сделки между
  разрешёнными менеджерами Bitrix24 и автоматически возвращать их;
- сохраняет исходного ответственного перед каждым изменением и проверяет
  результат после записи.

Инструкция по настройке и запуску: [`call_stats_bot/README.md`](call_stats_bot/README.md).

В [`integrations/callqueue`](integrations/callqueue) сохранена связанная часть
интеграции существующего webhook МегаФон: она асинхронно пересылает копию
события в SupportFlow, не мешая основному приложению очереди звонков.

## Секреты и данные

В репозитории не хранятся production `.env`, Telegram-токены, входящие
webhook Bitrix24, ключи МегаФон, SQLite-база и резервные копии. Для локальной
настройки используйте `call_stats_bot/.env.example`.
